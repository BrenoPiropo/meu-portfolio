O que é o Astreu Hub?

O Astreu Hub é uma plataforma mobile de exploração astronômica desenvolvida como Trabalho de Conclusão de Curso (TCC). A aplicação integra três pilares:

  1. Exploração Científica — Dados em tempo real de exoplanetas, estrelas, constelações e asteroides vindos da NASA, ESA e Caltech.
  2. Assistente de IA (RAG) — Chat inteligente que consulta artigos científicos reais antes de responder, eliminando alucinações.
  3. Comunidade — Feed social com artigos, fotos astronômicas, diário de bordo e metas de exploração.

Pipeline RAG (Como a IA Funciona)

1
Ingestão → PDFs do arXiv carregados via PDFLoader
2
Chunking → Texto dividido em blocos de 400 chars (overlap 80)
3
Embedding → Vetorização via mxbai-embed-large (Ollama local)
4
ChromaDB → Vetores armazenados com metadados
5
Busca → Top 4 chunks por similaridade de cosseno
6
Geração → Llama 3 responde com o contexto + referências

Diferencial: O LLM responde apenas com base no contexto recuperado. Se não encontra informação nos artigos, admite que não sabe.

Como Rodar o Projeto

Pré-requisitos

  • Node.js 18+, MySQL 8, Ollama, ChromaDB

Passos

# 1. Banco de dados
mysql -u root -p -e "CREATE DATABASE astreu_db;"

# 2. Modelos de IA
ollama pull llama3
ollama pull mxbai-embed-large

# 3. ChromaDB
chroma run --host 0.0.0.0 --port 8000

# 4. Backend
cd astreu-backend
npm install
npm run start:dev    # → http://localhost:3000

# 5. Seed (popular banco vetorial)
node seed.js

# 6. Frontend
cd ..
npm install
npx expo start       # → Escanear QR ou 'a' para Android

Pontos de Melhoria Identificados

  • ⚠️ Autenticação sem JWT (credenciais expostas na query string)
  • ⚠️ Senhas de banco hardcoded no código
  • ⚠️ Sem métricas de avaliação do RAG
  • ⚠️ Dataset sem curadoria (fotos reais misturadas com ilustrações)
  • ⚠️ Tradução PT→EN adiciona latência à busca vetorial
  • ⚠️ Artigos do arXiv sem filtro de confiabilidade
