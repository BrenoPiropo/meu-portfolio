1. Visão Geral do Projeto

O Minerva English App é um aplicativo mobile gamificado para o aprendizado de vocabulário em inglês, voltado para falantes de português brasileiro. Desenvolvido com React Native (Expo) no frontend e NestJS no backend, o app utiliza mecânicas de jogos — XP, níveis, ranking, ofensiva diária e desafios — para tornar o estudo de idiomas envolvente e eficaz.

5. Telas e Funcionalidades Detalhadas

5.1 Tela de Login (src/screen/login.tsx)

Função: Autenticação do usuário existente.

  • Campos: e-mail e senha
  • Validação: campos obrigatórios, .trim() no e-mail
  • Chamada API: POST /auth/login com { email, senha }
  • Sucesso: salva @Minerva:token, @Minerva:userId e @Minerva:user no AsyncStorage
  • Redirecionamento: /Categories
  • Componentes: ScreenWrapper, AppLogo
  • Fix aplicado: KeyboardAvoidingView com behavior={Platform.OS === 'ios' ? 'padding' : undefined} para eliminar trepidação da tela no Android

5.2 Tela de Cadastro (src/screen/register.tsx)

Função: Registro de novo usuário.

  • Campos: nome, e-mail, senha, confirmação de senha
  • Validações no frontend:
  • Todos os campos obrigatórios
  • Senha mínimo 6 caracteres
  • Senhas devem ser iguais
  • .trim() no e-mail e nome
  • Chamada API: POST /auth/register (fallback: POST /auth/cadastro)
  • Sucesso: salva token e perfil, redireciona para /Categories

5.3 Dashboard (src/screen/Categories.tsx)

Função: Hub principal de navegação com visão geral do progresso.

  • Exibe: nome do usuário, XP total, nível atual, ofensiva diária (streak)
  • Cards de navegação para todos os modos de jogo com ícones e cores distintas
  • Botão de acesso ao perfil

5.4 Flash Cards (src/screen/Home.tsx)

Função: Modo principal de estudo de vocabulário.

  • Busca palavras da API: GET /words
  • Embaralha as palavras para aleatorização
  • Renderiza componente WordCard com:
  • Palavra em inglês exibida
  • Pronúncia via Text-to-Speech (expo-speech)
  • Campo para o usuário digitar a tradução em português
  • Validação inteligente de resposta:
    • Aceita variações de gênero: aluno(a) → aceita "aluno" ou "aluna"
    • Aceita sinônimos separados por /: casa/lar → aceita "casa" ou "lar"
  • Feedback visual: verde (acerto) / vermelho (erro)
  • Registra resultado: POST /status/registrar com { id_usuario, id_word, tipo: 'acerto'|'erro' }
  • Barra de progresso animada mostrando avanço na sessão

5.5 Revisão Espaçada (src/screen/Review.tsx)

Função: Revisão de palavras erradas com sistema de repetição espaçada.

  • Busca palavras para revisão: GET /status/revisao/{userId}
  • Combina com lista local de wrongWords do context
  • Ao acertar na revisão: DELETE /status/{idStatus} para remover da lista
  • Usa o mesmo componente WordCard do Flash Cards
  • Se não houver palavras para revisar, redireciona ao início

5.6 Embaralhar Palavras (src/screen/WordScramble.tsx)

Função: Jogo de desembaralhar letras.

  • Carrega palavras do dicionário local (lista.ts)
  • Embaralha letras da palavra em inglês
  • Jogador toca nas letras para formar a palavra correta
  • Exibe dica com a tradução em português
  • Feedback visual: verde (correto) / vermelho (incorreto)
  • Registra XP ao acertar: POST /status/registrar

5.7 Enigma Master (src/screen/Charade.tsx)

Função: Jogo de charadas/enigmas em inglês.

  • Carrega charadas do componente charadesList
  • Exibe pista textual em inglês
  • Campo de texto para resposta
  • Animação de shake ao errar
  • Barra de progresso mostrando charadas resolvidas
  • Registra XP ao acertar: POST /status/registrar

5.8 Jogo da Forca (src/screen/Force.tsx)

Função: Versão digital do jogo da forca.

  • Carrega palavras e dicas do componente ForceList
  • Teclado alfabético na tela
  • 6 tentativas (representadas por corações)
  • Letras corretas: destacadas em verde
  • Letras erradas: destacadas em vermelho e desabilitadas
  • Exibe dica (tradução em português)
  • Registra XP ao vencer: POST /status/registrar

5.9 Tutor IA — Athena (src/screen/AiTutor.tsx)

Função: Chat com inteligência artificial para aprendizado de inglês.

  • Interface de chat com bolhas de mensagem (estilo WhatsApp)
  • Envia mensagens via: POST /words/ai-tutor (gateway no backend)
  • Backend redireciona para a API Google Gemini
  • A IA assume a persona "Athena", tutora de inglês que responde em PT-BR
  • Mantém histórico de conversação para respostas contextuais
  • Botão de Text-to-Speech para ouvir respostas da IA
  • Indicador de carregamento enquanto a IA processa

5.10 Desafios Diários (src/screen/Quests.tsx)

Função: Sistema de missões diárias com recompensas.

  • Busca desafios: GET /desafios/usuario/{userId}
  • Exibe cada desafio com:
  • Descrição da missão
  • Barra de progresso
  • Porcentagem de conclusão
  • Recompensa em XP
  • Ao completar: botão "Resgatar" chama POST /desafios/resgatar/{id}
  • Adiciona XP bônus ao perfil do usuário

5.11 Ranking Global (src/screen/Ranking.tsx)

Função: Placar de liderança entre todos os usuários.

  • Busca ranking: GET /ranking
  • Exibe lista ordenada por XP com:
  • Medalhas 🥇🥈🥉 para os 3 primeiros
  • Nome e pontuação de cada jogador
  • Destaque visual para o usuário logado ("Você")
  • Pull-to-refresh para atualizar

5.12 Perfil do Usuário (src/screen/perfil.tsx)

Função: Visualização de estatísticas e logout.

  • Busca estatísticas: GET /status/estatisticas/{userId}
  • Exibe:
  • Avatar com inicial do nome
  • Nome, e-mail, nível e XP
  • Cards de estatísticas: palavras estudadas, taxa de acerto, ofensiva, palavras para revisar
  • Botão de logout: limpa AsyncStorage e redireciona ao login

7. Serviços

7.1 API Client (src/service/api.tsx)

const api = axios.create({
  baseURL: 'https://minerva-backend-e0sa.onrender.com/',
});

// Interceptor: injeta Bearer Token JWT automaticamente
api.interceptors.request.use(async (config) => {
  const token = await AsyncStorage.getItem('@Minerva:token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

7.2 AI Service (src/service/aiService.tsx)

export async function chatWithAiTutor(
  message: string,
  conversationHistory: ChatMessage[]
): Promise<string>
  • Envia mensagem e histórico para POST /words/ai-tutor
  • Backend proxy redireciona para Google Gemini API
  • Retorna resposta textual da IA

9. Endpoints da API Backend

9.1 Módulo de Autenticação (/auth)

Método Endpoint Body Resposta Descrição
POST /auth/register { nome, email, senha } { token, user } Cadastro de novo usuário
POST /auth/cadastro { nome, email, senha } { token, user } Cadastro (endpoint alternativo)
POST /auth/login { email, senha } { token, user } Login com credenciais
GET /auth/me — { id_usuario, nome, email, xp, nivel } Perfil do usuário autenticado

9.2 Módulo de Palavras (/words)

Método Endpoint Body Resposta Descrição
GET /words — [{ id_word, ingles, portugues, exemplo }] Lista de todas as palavras
POST /words/ai-tutor { message, conversationHistory } { response } Gateway para chat IA (Gemini)

9.3 Módulo de Status/Progresso (/status)

Método Endpoint Body Resposta Descrição
POST /status/registrar { id_usuario, id_word, tipo } { success } Registra evento de estudo
GET /status/revisao/{userId} — [{ idStatus, word, ... }] Palavras para revisão espaçada
DELETE /status/{idStatus} — { success } Remove palavra da revisão
GET /status/estatisticas/{userId} — { total, acertos, streak, ... } Estatísticas do usuário

9.4 Módulo de Ranking (/ranking)

Método Endpoint Resposta Descrição
GET /ranking [{ nome, xp, nivel }] Placar global ordenado por XP

9.5 Módulo de Desafios (/desafios)

Método Endpoint Resposta Descrição
GET /desafios/usuario/{userId} [{ desafio, progresso, resgatado }] Desafios ativos do usuário
POST /desafios/resgatar/{id} { message, xpBonus } Resgata recompensa de XP

11. Fluxo de Autenticação

sequenceDiagram
    participant U as Usuário
    participant App as App (Frontend)
    participant AS as AsyncStorage
    participant API as Backend API

    Note over U,API: Primeiro Acesso
    U->>App: Abre o app
    App->>AS: Verifica @Minerva:token
    AS-->>App: null (sem token)
    App->>U: Exibe tela de Login

    U->>App: Digita email + senha
    App->>API: POST /auth/login
    API-->>App: { token, user }
    App->>AS: Salva token, userId, user
    App->>U: Redireciona para /Categories

    Note over U,API: Acessos Seguintes (Auto-Login)
    U->>App: Abre o app
    App->>AS: Verifica @Minerva:token
    AS-->>App: token encontrado!
    App->>U: Splash + Redirecionamento instantâneo → /Categories
    App->>API: GET /auth/me (background)
    API-->>App: Perfil atualizado
    App->>AS: Atualiza cache do perfil

    Note over U,API: Token Expirado
    App->>API: GET /auth/me
    API-->>App: 401 Unauthorized
    App->>AS: Remove token, userId, user
    App->>U: Exibe tela de Login
