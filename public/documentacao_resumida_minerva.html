1. O que é o Minerva?

Aplicativo mobile gamificado para aprendizado de vocabulário em inglês, voltado a falantes de português brasileiro. Combina flash cards, jogos (forca, enigmas, embaralhar palavras), tutor de IA, ranking global e desafios diários com um sistema de XP e níveis para manter o engajamento.

2. Stack Tecnológica

Camada Tecnologias
Frontend React Native (Expo 52), TypeScript, Expo Router, Axios, AsyncStorage, Expo Speech
Backend NestJS, TypeORM, MySQL, JWT + bcrypt, Passport, Helmet, ThrottlerGuard
IA Google Gemini API (gemini-1.5-flash) via gateway no backend
Infraestrutura Docker, Render (hospedagem), EAS Build (APK)

4. Endpoints da API

Autenticação

Método Endpoint Descrição
POST /auth/login Login → retorna JWT token + dados do usuário
POST /auth/register Cadastro de novo usuário
GET /auth/me Perfil do usuário autenticado (protegido por JWT)

Vocabulário e IA

Método Endpoint Descrição
GET /words/pratica Busca palavras para estudo (filtro por dificuldade e limite)
POST /words/ai-tutor Gateway para chat com IA Gemini

Progresso e Revisão

Método Endpoint Descrição
POST /status/registrar Registra acerto/erro de uma palavra (+10 XP por acerto)
GET /status/revisao/{userId} Palavras pendentes para revisão espaçada

Gamificação

Método Endpoint Descrição
GET /desafios/diarios Desafios diários do usuário
POST /desafios/resgatar/{id} Resgata recompensa de XP de desafio concluído
GET /usuarios/ranking Top 10 jogadores por XP

5. Fluxo de Autenticação (Resumo)

  1. Primeiro acesso → Usuário faz login/cadastro → Token JWT salvo no dispositivo
  2. Acessos seguintes → App detecta token salvo → entra direto no Dashboard (sem pedir senha)
  3. Token expirado → Backend retorna 401 → App limpa dados e exibe tela de login
  4. Logout manual → Usuário clica "Sair" no perfil → Token removido → Tela de login

6. Sistema de Gamificação

Mecânica Descrição
XP (Experiência) +10 XP por acerto nos jogos/flash cards
Níveis Nível = Math.floor(XP / 100) + 1
Ofensiva (Streak) Dias consecutivos de estudo
Desafios Diários 3 missões diárias com bônus de XP (30, 50, 100 XP)
Ranking Global Placar dos 10 melhores jogadores por XP total
Conquistas Badges desbloqueáveis (Primeiros Passos, Fogo nos Estudos, etc.)
